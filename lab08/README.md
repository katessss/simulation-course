## Цель работы

## Теоретические сведения

### Пуассоновский поток

**Пуассоновский (простейший) поток** — это поток событий, обладающий свойствами стационарности, ординарности и отсутствия последействия.

Интенсивность потока $\lambda$ — среднее число событий (заявок) в единицу времени.

### Экспоненциальное распределение интервалов

Интервалы времени между последовательными событиями в пуассоновском потоке распределены по **экспоненциальному закону** с параметром $\lambda$:

$$f(\tau) = \lambda e^{-\lambda \tau}, \quad \tau \geq 0$$

**Математическое ожидание интервала:**

$$M[\tau] = \frac{1}{\lambda}$$

### Распределение Пуассона

Число событий $X$ за интервал времени $T$ подчиняется **распределению Пуассона** с параметром $\lambda T$:

$$P(X = k) = \frac{(\lambda T)^k}{k!} e^{-\lambda T}, \quad k = 0, 1, 2, \ldots$$

**Теоретическое математическое ожидание:**

$$M[X] = \lambda T$$

**Теоретическая дисперсия:**

$$D[X] = \lambda T$$

Важное свойство: **для распределения Пуассона математическое ожидание равно дисперсии**.

## Алгоритм моделирования

### Генерация пуассоновского потока

1. Установить начальное время $t_{\text{текущ}} = 0$
2. Инициализировать пустой список моментов событий
3. Пока $t_{\text{текущ}} < T$:
   - Сгенерировать интервал $\tau$ из экспоненциального распределения с параметром $\lambda$
   - Увеличить текущее время: $t_{\text{текущ}} = t_{\text{текущ}} + \tau$
   - Если $t_{\text{текущ}} \leq T$, добавить момент события в список
4. Вернуть список моментов времени событий

**Реализация в коде:**
```python
def generate_flow(self):
    t_current = 0
    times = []
    
    while t_current < self.T:
        # Генерируем интервал из экспоненциального распределения
        tau = np.random.exponential(scale=1/self.lambda_rate)
        t_current += tau
        
        if t_current <= self.T:
            times.append(t_current)
    
    return times
```

### Статистический эксперимент

Для получения эмпирического распределения проводится серия из $N$ независимых экспериментов:

```python
def run_experiments(self):
    self.event_counts = []
```

## Вычисляемые характеристики

**Выборочное среднее:**
$$\hat{M} = \frac{1}{N} \sum_{j=1}^{N} X_j$$

**Выборочная дисперсия (несмещённая оценка):**
$$\hat{D} = \frac{1}{N-1} \sum_{j=1}^{N} (X_j - \hat{M})^2$$

**Выборочное стандартное отклонение:**
$$\hat{\sigma} = \sqrt{\hat{D}}$$

**Относительная погрешность математического ожидания:**
$$\delta_M = \frac{|\hat{M} - \lambda T|}{\lambda T} \cdot 100\%$$

**Относительная погрешность дисперсии:**
$$\delta_D = \frac{|\hat{D} - \lambda T|}{\lambda T} \cdot 100\%$$

### Анализ интервалов между заявками

Для последнего сгенерированного потока вычисляются средние интервалы между событиями:

**Выборочное среднее интервалов:**
$$\hat{\tau} = \frac{1}{n-1} \sum_{i=1}^{n-1} (t_{i+1} - t_i)$$

где $n$ — число событий в потоке, $t_i$ — момент $i$-го события.

**Теоретическое значение:**
$$M[\tau] = \frac{1}{\lambda} = \frac{1}{5.0} = 0.200 \text{ сек}$$

В типичном эксперименте: $\hat{\tau} \approx 0.200$ сек, что соответствует теоретическому значению.

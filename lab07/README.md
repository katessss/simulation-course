## Теоретические сведения

### Марковский процесс с непрерывным временем

**Марковский процесс с непрерывным временем** — случайный процесс $X(t)$, для которого будущее состояние зависит только от настоящего и не зависит от прошлого:

$$P(X(t_{n+1}) = j \mid X(t_n) = i, X(t_{n-1}), \ldots, X(t_0)) = P(X(t_{n+1}) = j \mid X(t_n) = i)$$

### Матрица интенсивностей Q

Процесс задаётся **матрицей интенсивностей переходов** $Q = [q_{ij}]$, где:

- $q_{ij}$ при $i \neq j$ — интенсивность перехода из состояния $i$ в состояние $j$
- $q_{ii} = -\sum_{j \neq i} q_{ij}$ — интенсивность ухода из состояния $i$

**Свойства матрицы Q:**
$$\sum_{j=1}^{n} q_{ij} = 0, \quad \forall i$$

### Время пребывания в состоянии

Время пребывания в состоянии $i$ распределено **экспоненциально** с параметром $\lambda_i = |q_{ii}|$:

$$f(\tau) = \lambda_i e^{-\lambda_i \tau}, \quad \tau \geq 0$$

**Математическое ожидание времени пребывания:**

$$M[\tau_i] = \frac{1}{\lambda_i} = \frac{1}{|q_{ii}|}$$

### Вероятности переходов

При выходе из состояния $i$ вероятность перехода в состояние $j$ определяется пропорционально интенсивности:

$$p_{ij} = \frac{q_{ij}}{\lambda_i} = \frac{q_{ij}}{|q_{ii}|}, \quad j \neq i$$

### Стационарное распределение

**Стационарное распределение** $\pi = [\pi_1, \pi_2, \ldots, \pi_n]$ — вектор долей времени, проводимых в каждом состоянии в долгосрочной перспективе. Определяется из системы уравнений:

$$\pi Q = 0$$
$$\sum_{i=1}^{n} \pi_i = 1$$

Это эквивалентно поиску собственного вектора транспонированной матрицы $Q^T$ для собственного значения $\lambda = 0$:

$$Q^T \pi^T = 0$$

## Алгоритм моделирования

### Генерация одного перехода

1. Находим текущее состояние $i$ и интенсивность ухода $\lambda_i = |q_{ii}|$
2. Генерируем время пребывания из экспоненциального распределения:
   $$\tau = -\frac{\ln(U)}{\lambda_i}$$
   где $U \sim U(0, 1)$ — равномерное случайное число
3. Вычисляем вероятности переходов в другие состояния:
   $$p_j = \frac{q_{ij}}{\lambda_i}, \quad j \neq i$$
4. Выбираем следующее состояние случайным образом согласно вероятностям $p_j$
5. Сохраняем текущее состояние и длительность $(i, \tau)$ в историю
6. Переходим в следующее состояние

**Реализация в коде:**
```python
def step(self):
    # Интенсивность ухода из текущего состояния
    lambda_total = abs(self.transition_matrix[self.current_state - 1, 
                                             self.current_state - 1])
    
    # Генерация времени пребывания
    duration = random.expovariate(lambda_total)
    
    # Вероятности переходов
    rates = self.transition_matrix[self.current_state - 1].copy()
    rates[self.current_state - 1] = 0  # Обнуляем диагональ
    probabilities = rates / lambda_total
    
    # Сохранение в историю
    self.history.append((self.current_state, duration))
    
    # Выбор следующего состояния
    next_state = np.random.choice([1, 2, 3], p=probabilities)
    self.current_state = next_state
    
    return next_state, duration
```

### Вычисление стационарного распределения

Решение системы $\pi Q = 0$ эквивалентно поиску собственного вектора:

```python
def get_stationary_distribution(self):
    Q = self.transition_matrix
    eigenvalues, eigenvectors = np.linalg.eig(Q.T)
    idx = np.argmin(np.abs(eigenvalues))  # Находим λ ≈ 0
    stationary = np.real(eigenvectors[:, idx])
    return stationary / stationary.sum()  # Нормализация
```

### Вычисление эмпирического распределения

Эмпирическое распределение — доля времени, проведённого в каждом состоянии:

$$\hat{\pi}_i = \frac{\sum_{k: s_k = i} \tau_k}{\sum_{k=1}^{N} \tau_k}$$

где $s_k$ — состояние в $k$-м переходе, $\tau_k$ — длительность пребывания.

**Реализация:**
```python
def get_empirical_distribution(self):
    total_time = sum(dur for state, dur in self.history)
    times = {1: 0, 2: 0, 3: 0}
    for state, dur in self.history:
        times[state] += dur
    return np.array([times[1]/total_time, 
                     times[2]/total_time, 
                     times[3]/total_time])
```

### Зависимость от числа переходов

| Число переходов | Максимальная относительная ошибка, % |
|----------------|-------------------------------------|
| 10 | 15–30 |
| 100 | 1–5 |
| 1000 | 0.3–1.0 |
| 10000 | <0.3 |

С увеличением числа переходов (длительности наблюдения) относительные погрешности **монотонно убывают**, что соответствует эргодической теореме для марковских процессов.

### Закон больших чисел для марковских процессов

Для эргодического марковского процесса справедливо:

$$\lim_{T \to \infty} \frac{1}{T} \int_0^T \mathbb{1}\{X(t) = i\} \, dt = \pi_i$$

То есть доля времени, проведённого в состоянии $i$, сходится к стационарной вероятности $\pi_i$.

6. **Визуализация непрерывного процесса**: Разработанный графический интерфейс позволяет наблюдать эволюцию системы в непрерывном времени, что отличает данную модель от дискретных марковских цепей.
